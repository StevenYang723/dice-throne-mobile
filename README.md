# 王权骰铸 · 掌上对决

手机优先的中文、单人 AI 对战网页，纯静态部署。无需注册，AI 和自动存档都在浏览器本地运行。

**当前是 v0.4 规则开发版，不是第一季、第二季、漫威的完整原版复刻。**

## 在线游玩

https://stevenyang723.github.io/dice-throne-mobile/

手机浏览器打开即可游玩，也可使用浏览器的“添加到主屏幕”。首次访问需要网络。第一季采用 8 人 ReRolled 资料；中文名称使用说明性译名。

## 已实现与范围

- 三个系列共 24 名英雄的规则资料；19 名英雄开放基础对战。
- 50 起始生命、60 生命上限、CP、手牌、三次投骰、锁骰、技能宣告、防御与伤害结算。
- 18 张通用牌，以及已接入的专属牌、升级牌和状态。各英雄牌库目前仍是子集，**不是完整原版 32 张牌库**。
- 本地策略 AI、两种投骰偏好、断点续玩、对战记录、触屏和桌面布局。
- 24 名英雄的官方公开插画，应用于大厅卡面、战场头像和英雄详情。完整来源见 [美术清单](ART-CREDITS.md)。
- 按英雄区分的攻击特效、掷骰动画、生命变化与状态浮字、升级与格挡反馈；特效可关闭并遵循系统减少动态效果设置。

尚未开放：树精、机械师、黑寡妇、奇异博士、血族领主。其伙伴、合成、升级组合和法术系统仍需完整实现与验证。当前选择交互覆盖已经接入的技能、状态与卡牌；参考资料中的其他升级和行动牌仍未进入牌库。海盗镜像局的双方金币归属等特殊边界仍需进一步建模。不能据此进行原版规则裁定。

页面“版本说明”显示各英雄的当前接入状态。未支持的技能会禁用，未接入的卡牌不会加入对战牌库。`rules.json` 中 `referenceCards` 和 `referenceUpgrades` 保留后续接入所需的资料。

## 本地运行

需要 Node.js 20 或更新版本，无第三方依赖：

```sh
node server.mjs
```

打开终端显示的本地地址（默认 http://127.0.0.1:4173）。不要直接双击 HTML：规则文件需要 HTTP 加载。

```sh
npm test
node build.mjs
```

构建会将运行文件复制到 `dist/`。也可以直接将仓库根目录部署到 GitHub Pages（`main` 分支、`/ (root)`）。全部资源使用相对地址，支持项目子路径。

## 验证

46 项自动化测试：覆盖开局、锁骰、顺子、终极技能、眩晕、收入、生命上限、防御升级、已接入卡牌操作、361 组基础策略对局，以及 19 组使用实际 AI 出牌和状态的完整对局。选择测试另检查 80 个升级技能分支、暂停恢复、支付与随机数不重复、目标归属、数量边界和 AI 响应。手机尺寸浏览器检查了多选骰、可选弃牌、幻象排列及刷新后继续选择。

这些测试验证当前实现的行为与运行稳定性，不代表所有原版规则已经核准。

## 文件

- `engine.mjs`：独立规则引擎、种子随机数和 AI。
- `choice-flow.mjs` / `interaction-rules.mjs`：可存档的暂停选择、响应时机与角色交互。
- `app.mjs` / `style.css`：界面、交互和本地存档。
- `rules.json` / `common.mjs`：英雄与通用牌资料。
- `engine.test.mjs`：可重复运行的回归测试。

## v0.2 界面更新

规则说明、骰面、状态编号与升级牌名称统一显示中文。状态标记在战场、技能、卡牌、详情及日志中使用粗体和分类颜色。待核实或核心技能未接入的英雄无法选取，也不会成为随机电脑对手。详见 [规则复核记录](RULES-REVIEW.md)。

## v0.3 美术与特效

24 张插画来自官方英雄网站，保留原图、部署到同一站点，无第三方运行时图片请求。手机大厅使用延迟加载，战场只加载双方头像。技能特效使用独立 Canvas 层，最多 110 个粒子、5 条轨迹、1.5 倍像素比；空闲和切到后台时停止绘制。动画不消耗规则随机数，不修改骰值和结算。生命浮字显示实际净生命变化；受击与格挡仅在结算完成后触发。

自动化验证增加特效事件与规则状态隔离检查；原有规则范围和 5 名禁选角色保持不变。

## v0.4 效果选择与响应

- 遇到选牌、选骰、目标、消耗数量或技能分支时暂停结算，由效果所属玩家选择；电脑不会替玩家确认。允许放弃的效果有跳过选项。
- 雷神弃牌与雷锤机会、连锁闪电选骰，洛基幻象暗排与抽牌、封咒与诡计袋分配，惊奇队长射线选骰，绯红女巫召唤与概率操纵均接入选择流程。
- 忍术六点分支、荣誉用量、奈拉最终伤害分摊、枪斗胜利分支、海盗接受金币与赎金、炽天使净化等使用实际结算时的数据。
- 额外骰提供合法改骰响应；防御后保留攻击修正窗口；普通防御可以跳过。维持阶段由当前玩家决定顺序，强制效果仍必须结算。
- 已入牌库的升级保留全部子技能。武僧连击升级逐枚选择奖励，忍者防御重掷按每次防御计算。状态溢出前提供适用的消耗选择。
- 当前可用状态与专属能力集中显示；选择节点自动保存。存档通过原始动作、种子和已确认选择恢复，不会重复支付、抽牌或掷骰。

旧版本存档仍能读取；旧版已结算的自动选择不会被追溯重做。完整牌库与未核实角色没有因此开放。规则参考：[时机与阶段](https://dice-throne.rulepop.com/#timing)、[维持阶段](https://dice-throne.rulepop.com/#upkeep-phase)、[官方英雄与状态索引](https://dice-throne.rulepop.com/)。
